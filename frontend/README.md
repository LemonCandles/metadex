# Frontend do Metadex

Interface web do Metadex, construída com Next.js, TypeScript, Tailwind CSS e shadcn/ui.

## Desenvolvimento

Instale as dependências e inicie o servidor:

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

A aplicação ficará disponível em <http://localhost:3000>.

## Verificações

```bash
pnpm lint
pnpm build
```
